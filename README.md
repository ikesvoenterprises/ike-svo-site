## Checkout link

The Complete System checkout is `https://payhip.com/b/asC7j`. It is centralized near the top of `script.js` as `completeSystemCheckoutUrl`; the same URL also appears as an HTML fallback and in the product structured data in `svo-physique.html`.

## Deployment

Netlify publishes the repository root. Merging or committing the final files to the connected production branch triggers deployment.
